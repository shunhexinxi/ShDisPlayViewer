ShDisplayViewer 应用图标
设计：蓝色地球、金色演练路径节点和播放符号；没有小字号文字，适合桌面和任务栏。
shdisplayviewer.svg 是可编辑的矢量源文件。
shdisplayviewer-16.png 至 shdisplayviewer-512.png 用于 Qt 和 Ubuntu 图标主题。
shdisplayviewer.ico 包含 16、24、32、48、64、128、256 像素图像，用于 Windows EXE。
修改 SVG 后，在工程中安装 Node.js/sharp，再执行 node scripts/render-app-icon.cjs。
所有成品图标均随源码保存，普通编译不需要 Node.js 或 sharp。
