# 源码与二进制发布边界

Viewer、VideoSDK 自研源码及随附已授权素材按根目录 Apache-2.0 公开；维护署名为 shunhe，开发者为青岛顺和信息技术有限公司。发布方已确认自研代码及内部开发人员署名范围。第三方组件保留自己的许可证，不通过改名改变上游权利。

## 源码仓包含

- Viewer 应用和演练模块、测试、构建脚本。
- VideoSDK 封装源码及接口；FFmpeg/Qt 开发库由构建者另行准备。
- FreeEarthSDK 公共接口与接入说明，不含实现或 DLL/.so。
- 清洁的默认项目与 TMS/XYZ 占位配置模板。
- 已授权图标、纹理、模型及虚构城市火灾示例。
- 操作手册、配置、构建、贡献和 SDK 说明。

公开默认场景不附带现场影像、高程、矢量数据、缓存、摄像机地址或真实项目。

## 独立下载附件

FreeEarthSDK 二进制开发包与完整 Viewer 运行包应分别作为下载附件。SDK 自研实现闭源，专用模式为 Viewer 免费免激活、第三方产品独立集成 SDK 另行商业授权。条款准备稿见 [FREEEARTH_VIEWER_TERMS_DRAFT.md](FREEEARTH_VIEWER_TERMS_DRAFT.md)，实际附件应携带发布方审定的最终条款。

技术 SDK 包不等于完整 Viewer 安装包；SDK 不含全部第三方开发环境。发布完整运行包时需按实际库和构建选项整理第三方声明与对应源码获取资料。

现场部署包中的地图服务地址、数据与缓存不直接用于公开下载。若以后提供公开演示地图，应另行选择有明确分发权的数据和合法可访问的服务，重新检查包内容及启动。

## 导出与检查

```bash
python3 scripts/export-public.py --name source-candidate
python3 scripts/check-public.py exports/source-candidate
```

从生成目录取**内容**作为仓库根，或使用本次已交付的干净源码包。不要把内部工程整体推送到 GitHub。导出仅访问指定源码树、模板和文档，进入前会剪除地图瓦片、缓存、私有实现、构建与依赖目录；检查不输出命中的敏感文本。

自动检查能发现明显内网地址、字面量凭据、私有路径和二进制误带，不能证明版权归属、所有许可证义务或所有环境兼容性。发布人仍需核对真实权利范围、下载附件及仓库说明。
