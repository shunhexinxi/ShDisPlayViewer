- 本批公开候选配合独立 SDK 开发包的 Windows/Ubuntu PACKAGE 模式 Release 构建及 CTest；之前桌面冒烟仍是原批次记录。
- 独立源码导出工具能否重新导出并通过检查。

具体结果由本次交付包外的上传准备报告和机器可读记录提供；不要将旧现场构建结果直接当成本批源码的验证结果。
