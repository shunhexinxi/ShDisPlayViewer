# 验证范围

本次公开版从当前 Windows Viewer 源码取得新快照，合并 Ubuntu 已验证的本地标注父级显隐修复，移除源代码示例里的固定设备凭据，并按发布方确认统一自研 SDK 维护署名。未改写现场配置或原 Qt 客户端。

## 检查项目

- 源码边界、许可证文件、第三方声明、公开接口与目录完整性。
- XML 和示例数据、Qt 资源文件引用、文档内部链接。
- 明显内网地址、字面量凭据、个人联系方式、SDK 二进制和私有实现误带。
- 公开候选配合独立 SDK 开发包的 Windows/Ubuntu PACKAGE 模式 Release 构建、CTest 及桌面冒烟。
- 独立源码导出工具能否重新导出并通过检查。

具体结果由本次交付包外的上传准备报告和机器可读记录提供；不要将旧现场构建结果直接当成本批源码的验证结果。

## 限制

默认项目是空白地球，桌面冒烟只验证地图引擎初始化、界面和安全示例播放，不能证明某个在线地图或实际摄像机可达。RTSP 设备、编码、音频和硬件解码仍需使用者在目标设备验证。

Ubuntu 在已配置依赖的 22.04 x86_64 主机验证，不保证任意发行版、显卡、编译器或第三方库版本兼容。SDK 下载附件的技术验证不等于已经完成二进制许可条款和所有依赖再分发审核。

完整地图及外部动作验收参照 [ACCEPTANCE.md](ACCEPTANCE.md)，产品使用参照 [USER_GUIDE.md](USER_GUIDE.md)。
