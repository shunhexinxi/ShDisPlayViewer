# ShEarthSDK 与 ShVideoSDK Viewer 专用条款草案

维护方：shunhe；开发者：青岛顺和信息技术有限公司。更新：2026-10-14。

本稿用于维护方审定，尚不作为已生效的二进制分发授权。公开 Viewer 源码与公共接口声明按各自公开许可使用；SDK 自研实现和二进制另行授权。

1. ShEarthSDK 与 ShVideoSDK 的自研实现保持闭源。开发包仅提供公共头文件、库文件、CMake 元数据及必要的说明和声明，不提供内部头文件、CPP 实现、私有构建脚本或调试源码。
2. 拟允许用户免费、免激活运行 ShDisplayViewer，并使用专用 SDK 构建、修改及分发仍以本项目地图步骤演练功能为主体的 Viewer 衍生版。
3. 拟允许按最终条款随 Viewer 再分发原样 SDK 二进制或开发包，并保留适用声明。独立产品集成、SDK 再销售等范围另行商业授权。
4. 行业定制、系统集成、部署与培训可作为独立付费服务；Viewer 核心功能不以激活或商务联系为前提。
5. Qt、FFmpeg、OSG/osgEarth 等第三方组件保留各自许可证。SDK 闭源不减少第三方许可已经赋予的权利或相应分发义务。
6. 自 2026-10-14 起的发布方式调整不撤销历史版本已经授予的 Apache-2.0 权利；若历史版本已公开，应保留对应版本及原许可的说明。
7. 二进制包需标明平台、架构、接口与依赖版本、校验值。最终适用范围、责任、支持、生效方式及其他细则由维护方定稿。
