# 使用与验收清单

1. 未配置 IMS，直接启动；出现动态演练页，无登录/激活界面。
2. 打开默认虚构方案，播放三个步骤。检查到达后显现、闪烁、累计展示、暂停/继续、前后步、时间轴跳转、停止和循环。
3. 新建方案/步骤并绘制标记，修改属性、几何和视角，退出重开确认保存。
4. 普通标记和动态标记属性窗体大小一致。两处配置鼠标动作，单击执行；鼠标视频动作暂停演练。动态标记自动动作在标记出现时执行，演练继续播放；闪烁、暂停/继续不重复触发，预览和拖动时间轴不触发，循环/重播再次执行。
5. 使用统一地址/程序路径字段，检查 Windows/Ubuntu 当前平台路径、带空格的路径和参数。旧双路径方案保存后保留另一平台原值；新动作换平台时检查路径。含自动程序动作的预案在播放前一次确认。缺少当前平台路径时应提示。
6. 进入演示模式，修改标记和步骤后退出；原方案应保持进入前状态。另存演示结果后可以独立打开。
7. 导出项目至空目录，在另一台电脑打开。登记资源存在，外部地图/程序给出检查提示，地图瓦片和缓存不出现在导出目录。
8. 配置 HTTP TMS 或 `.earth`，验证加载、缩放、地图模式；断网时编辑/保存仍可工作，服务图层可以不可用。
9. 在 Ubuntu 22.04 x86_64 和后续选定版本检查启动、中文字体、OpenGL、键鼠和 RTSP，不能用 Windows 测试替代。
10. 视频和本次启动的独立程序分别验证无动作、10秒、30秒、1分钟关闭。计时从启动开始，不受演练暂停/停止影响；提前关闭取消计时，不影响其他窗口或已有程序。网页恢复固定为无动作。
11. 两端蓝色标题栏一致，无保存/演示副本/窗口全屏工具栏按钮；在项目菜单保存、进入/退出演示副本。标题栏全屏后仍可点击同一按钮还原，检查 F11/Esc、标题栏拖动、Ubuntu 边缘调整尺寸，以及地图全屏退出后恢复布局。

11 项自动测试覆盖动态时序、XML 往返、普通标注与分组、几何/测量、图层和环境表单、动作类型过滤、统一/旧平台路径、自动触发及去重、属性窗体尺寸、视频/程序10秒计时关闭、项目资源清单及演示副本隔离。四种恢复选项的编辑保存均有测试；现场30秒/1分钟计时及真实RTSP解码另行实测。

现场 RTSP、真实地图服务、显卡兼容和长时间演练属于设备/环境实测项目，结果单独记录，不能由单元测试通过推导。
